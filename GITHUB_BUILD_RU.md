# Сборка Tokyo Ghoul RPG через GitHub Actions

1. Создай репозиторий на GitHub.
2. Загрузи содержимое этой папки так, чтобы `build.gradle` и `src` были в корне репозитория.
3. Открой вкладку **Actions**.
4. Выбери **Build Tokyo Ghoul RPG** и нажми **Run workflow**.
5. После успешной сборки открой завершённый запуск и скачай artifact `TokyoGhoulRPG-1.2.0`.
6. Внутри будет `.jar` для Minecraft Forge 1.20.1.

Проект рассчитан на Minecraft Forge 1.20.1 и Java 17.
